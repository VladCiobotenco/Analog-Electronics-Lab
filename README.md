# Analog Electronics Lab

A comprehensive collection of Python scripts for visualizing and analyzing fundamental concepts in analog electronics. This repository provides interactive plots and simulations for key electronic components and circuits.

## Overview

This project contains educational Python scripts that demonstrate various aspects of analog electronics through mathematical modeling and visualization. Each script generates detailed plots to help understand the behavior and characteristics of different electronic components.

## Scripts

### 1. **Diode.py**
Analyzes the behavior of semiconductor diodes with mathematical models and characteristic curves.
- **Features**: 
  - I-V characteristic curves
  - Forward and reverse bias analysis
  - Non-linear behavior visualization

### 2. **Tranzistor.py**
Explores transistor operation and characteristics for both BJT and amplification scenarios.
- **Features**:
  - Collector-Emitter characteristics
  - Base-Emitter relationships
  - Transistor operating regions (cut-off, active, saturation)

### 3. **AmplificatorOperational.py**
Simulates operational amplifier (op-amp) circuits and their behavior.
- **Features**:
  - Gain and frequency response analysis
  - Common amplifier configurations
  - Transfer characteristics

### 4. **AmplificatorCuEmitorComun.py**
Analyzes common-emitter amplifier circuits with transistors.
- **Features**:
  - Voltage gain calculations
  - Input/output impedance characteristics
  - Frequency response

### 5. **Surse.py**
Studies voltage and current source characteristics and behavior.
- **Features**:
  - Ideal vs real source models
  - Load line analysis
  - Power transfer characteristics
